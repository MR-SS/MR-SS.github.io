# Sajjad Rahim Nouri

**Software Security Engineer | Application Security · DevSecOps · Security Research**

I work on making security a practical part of software engineering—from secure development practices and code review to CI/CD security, vulnerability management, and software supply-chain assurance.

My experience spans consumer platforms, cloud infrastructure, and financial technology. I am currently focused on improving Secure SDLC practices and establishing pragmatic DevSecOps controls in a regulated payment environment.
